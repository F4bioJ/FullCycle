# O que devemos avaliar

## Avaliar o prompt, e não o modelo

A evaluation também pode ser do modelo: mantém-se o mesmo prompt e trocam-se os modelos para ver qual performa melhor e gasta menos. Neste capítulo o foco é o contrário, mudar o prompt e entender as métricas, os avaliadores e os conceitos para fazer isso. Uma pequena mudança no prompt pode melhorar ou degradar a performance, e a avaliação é um processo contínuo, inclusive com testes em produção.

## Três perguntas para começar

Antes de avaliar qualquer prompt, é preciso responder: por que avaliar (o objetivo), quais tipos de avaliação usar (o como) e quem vai avaliar. Conforme as respostas, o processo muda bastante. Segundo o professor, entender o objetivo é a parte mais difícil, porque exige pensar no que se quer; como há muitos tipos de avaliação e de avaliadores, é a clareza do objetivo que orienta a escolha.

## Comparar um prompt com outro

Para comparar prompts é preciso um dataset, um critério do que é melhor ou pior e uma análise. O dataset é o mesmo para todos os prompts: com a mesma entrada, observam-se as saídas melhores ou piores de cada um.
