# Introdução a Prompt Enrichement

## Um tema subestimado

O professor abre o capítulo com Query Reformulation e Prompt Enrichment, um assunto que ele considera muito importante e que costuma ser subestimado quando se trabalha com IA.

## O problema: a pergunta mal feita do usuário

Muitas vezes se gasta muito dinheiro com IA por um único motivo: o usuário final faz uma pergunta mal feita, ou seja, um prompt ruim. A resposta vem pouco clara ou sem todo o material necessário, e o usuário continua iterando com o sistema. O resultado é gasto maior de tokens e, pior ainda, um usuário insatisfeito com a resposta, que passa a culpar o sistema.

## O objetivo do capítulo

A pergunta que guia o capítulo é: como ajudar o usuário a obter respostas melhores da IA, sabendo que ele vai fazer perguntas "erradas" ou incompletas? O professor trata de dois aspectos:

- **Reformular perguntas**, principalmente para buscá-las em ambientes externos e trazer as informações mais relevantes.
- **Aplicar técnicas que melhoram o prompt**, para que ele produza respostas melhores.

O capítulo também terá exemplos práticos com código para mostrar essa diferença.
